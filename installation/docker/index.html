通过 Docker 安装

先决条件¶

在开始安装之前，请确保满足以下条件：

  • 系统已安装 Docker。如果尚未安装 Docker，请按照官方 Docker 安装指南 进行安装。
  • 能够连接互联网以下载 Ferron Docker 镜像。

安装步骤¶

1. 拉取 Ferron Docker 镜像¶

要从 Docker Hub 下载最新的 Ferron 镜像，请运行以下命令：

docker pull ferronserver/ferron:2

2. 运行 Ferron 容器¶

镜像下载完成后，使用以下命令启动 Ferron 容器：

docker run --name myferron -d -p 80:80 --restart=always ferronserver/ferron:2

该命令执行以下操作：

  • --name myferron：为运行的容器指定名称（myferron）。
  • -d：以分离模式（后台）运行容器。
  • -p 80:80：将容器的 80 端口映射到宿主机的 80 端口。
  • --restart=always：确保容器在停止或系统重启时自动重启。

验证安装¶

要确认 Ferron 是否正在运行，请执行：

docker ps

此时应显示一个名为 myferron 的运行中容器。

要测试 Web 服务器，请打开浏览器并访问 http://localhost。您应该会看到 Ferron 的默认欢迎页面。

或者，也可以使用 curl 进行测试：

curl http://localhost

文件结构¶

Docker 中的 Ferron 具有以下文件结构：

  • /usr/sbin/ferron - Ferron Web 服务器
  • /usr/sbin/ferron-passwd - Ferron 用户密码生成工具
  • /usr/sbin/ferron-yaml2kdl - Ferron 配置转换工具
  • /var/cache/ferron-acme - Ferron 的 ACME 缓存目录（如果未在服务器配置中显式指定）
  • /var/log/ferron/access.log - Ferron 访问日志（Combined Log Format，默认配置）
  • /var/log/ferron/error.log - Ferron 错误日志（默认配置）
  • /var/www/ferron - Ferron 的 Web 根目录
  • /etc/ferron.kdl - Ferron 配置文件

管理 Ferron 容器¶

停止容器¶

要停止 Ferron 容器，请运行：

docker stop myferron

重启容器¶

要重启容器，请运行：

docker start myferron

删除容器¶

如果需要删除 Ferron 容器，请运行：

docker rm -f myferron

使用 Docker Compose 运行 Ferron¶

如果您使用 Docker Compose，可以在 docker-compose.yml 文件中为 Ferron 定义一个服务：

services:
  ferron:
    image: ferronserver/ferron:2
    ports:
      - "80:80"
    restart: always

然后，可以使用以下命令启动 Ferron：

docker-compose up -d

示例：使用 Docker Compose 和自动 TLS 的 Ferron¶

如果使用 Docker Compose 并启用自动 TLS，可以使用以下 docker-compose.yml 文件内容：

services:
  # Ferron 容器
  ferron:
    image: ferronserver/ferron:2
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - "./ferron.kdl:/etc/ferron.kdl" # Ferron 配置文件
      - "ferron-acme:/var/cache/ferron-acme" # 此卷用于持久化自动 TLS 缓存，否则 Web 服务器每次重启都会获取新证书
    restart: always

volumes:
  ferron-acme:

您还可以在 "ferron.kdl" 文件中这样配置 Ferron：

// 将 "example.com" 替换为您网站的域名
example.com {
    root "/var/www/ferron"
}

然后，可以使用以下命令启动 Ferron：

docker-compose up -d

Ferron 镜像标签¶

Ferron 为 Ferron 镜像提供了以下标签（适用于 Ferron 2）：

  • 2 - 基于 Distroless，静态链接二进制文件
  • 2-alpine - 基于 Alpine Linux，静态链接二进制文件
  • 2-debian - 基于 Debian GNU/Linux，动态链接二进制文件（需要 GNU libc）
