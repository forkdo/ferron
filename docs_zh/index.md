**欢迎来到 Ferron 文档！** Ferron 是一款快速、现代且易于配置的 Web 服务器，支持自动 TLS 证书管理。如果您是 Ferron 的新手，您提供网站的方式即将改变——您将能够快速让网站上线。

要浏览文档，请单击侧边栏中的其中一个位置，或者进入右上角的菜单，然后单击菜单中的其中一个位置。

## 第一次使用？

**您是 Ferron 新手？没问题。** 从[入门指南](/docs/getting-started)开始，了解 Web 服务器的基础知识，并决定您应该使用静态文件服务、反向代理还是混合设置。

之后，使用其中一种可用的安装方法安装 Ferron，然后阅读常见使用场景。

如果您想进一步了解 Ferron 的配置，可以阅读[配置参考](/docs/configuration/fundamentals)。

如果出了问题，请从[故障排查指南](/docs/troubleshooting)开始。

**无论您做什么，都请享受使用您的新 Ferron 服务器！** 😄

## 如果您对 Ferron 有疑问

如果您对 Ferron 有任何疑问，可以在[支持页面](/support)上选择其中一种可用的方式。我们随时为您提供帮助！

如果您怀疑 Ferron 存在 bug，可以在我们的 GitHub 仓库[提交 issue](https://github.com/ferronweb/ferron/issues)。

**感谢您参与 Ferron 社区！** 😊
